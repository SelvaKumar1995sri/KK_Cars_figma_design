# Quick Start Guide

Get your AutoElite car dealership website running in 3 simple steps!

## 🚀 Step 1: Create Your Account

1. Click **"Sign In / Register"** in the top-right corner
2. Switch to the **"Sign Up"** tab
3. Enter your details:
   - Full Name
   - Email
   - Password
4. Click **"Create Account"**

## 👑 Step 2: Become Admin

After signing in, you'll see a **"Quick Setup"** panel in the bottom-right corner:

1. Click **"Become Admin"** button
2. Wait for the success message
3. **Refresh the page** to see the "Admin" link in the navigation

## 📊 Step 3: Load Sample Data

In the same Quick Setup panel:

1. Click **"Load Sample Data"** button
2. This will add:
   - 3 sample cars (BMW, Porsche, Range Rover)
   - 3 customer testimonials
   - 5 sales records for analytics
3. **Refresh the page** to see all the data

## ✅ You're All Set!

Now you can:

### As a Regular User:
- ✨ Browse cars on the homepage
- 🔍 Click any car to view details (login required)
- 📧 Submit enquiries for cars you're interested in
- ⭐ Read customer testimonials

### As an Admin:
- 📊 View comprehensive analytics dashboard
- ➕ Add new cars to inventory
- 🗑️ Remove cars from listings
- 📨 Manage customer enquiries
- 💰 Track sales and profits
- ⭐ Add customer testimonials

## 🎨 What You'll See

### Home Page Features:
- Stunning hero section with call-to-action
- Featured vehicles with pricing and specs
- Customer testimonials carousel
- Premium orange-to-red gradient design

### Admin Dashboard Features:
- **Statistics Cards**: Total sales, profit, enquiries, conversions
- **Monthly Sales Graph**: Bar chart showing sales and profits
- **Brand Distribution**: Pie chart of sales by car brand
- **Management Tabs**:
  - 🚗 Manage Cars
  - 🔔 Enquiries (with notification badges)
  - 💵 Sales Records
  - ⭐ Testimonials

## 💡 Pro Tips

1. **Google Sign-In**: To enable Google OAuth, follow instructions in README.md
2. **Mobile Friendly**: The site is fully responsive - try it on your phone!
3. **Animations**: Scroll through the homepage to see smooth animations
4. **Quick Setup Panel**: You can dismiss it once you're done with initial setup

## 🆘 Need Help?

If something doesn't work:
1. Check the browser console (F12) for errors
2. Make sure you refreshed the page after becoming admin
3. Verify you clicked "Load Sample Data" if the homepage is empty
4. For Google OAuth issues, see README.md
